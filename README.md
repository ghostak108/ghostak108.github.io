# ZweiKlang

Öffentliche Website: https://ghostak108.github.io/

Statische Website mit HTML, CSS und JavaScript. GitHub Pages veröffentlicht automatisch aus `main` / Repository-Wurzel. Kein Build und keine Installation nötig.

## Inhalte bearbeiten

- `index.html`: Startseite, Musik, Sessions, Duo, Live und Booking
- `about.html`: Das Duo
- `videos.html`: Alle elf Sessions mit Suche
- `events.html`: Eventarchiv
- `contact.html`: Kontakt, Impressum und Datenschutz
- `style.css`: Responsive Gestaltung und Animationen
- `app.js`: Navigation, Suche, SoundCloud und Booking
- `assets/`: Bilder und Logos

Das Booking-Formular bereitet eine E-Mail im lokalen Mailprogramm vor. SoundCloud wird erst nach einem Klick geladen. Keine eigenen Analyse-Tracker.

Die frühere Custom Domain zweiklang.live wurde aus GitHub Pages entfernt, damit die GitHub.io-Adresse direkt erreichbar ist. Der frühere Stand bleibt in der Commit-Historie erhalten.
